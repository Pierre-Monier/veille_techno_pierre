# Profil — Pierre Monier

Développeur Flutter Senior / Lead, 5+ ans d'expérience en mobile.

## Points forts (une offre « forte » colle à ça)

- **Flutter / Dart** : cœur de métier. Architecture modulaire (Clean Architecture,
  Feature-First, MVVM), gestion d'état Riverpod, monorepo Melos, conception de SDK.
- **Plugins natifs** : Swift / Kotlin, MethodChannel, intégration BLE / IoT.
- **CI/CD** : GitLab CI, GitHub Actions, Fastlane, Codemagic, Bitrise.
- **Backend d'appoint** : Firebase, GCP.
- **Lead & mentorat** : pilotage d'équipe mobile, guidelines, revue d'architecture.
- Expérience secondaire : React Native, et full-stack React/Node/Java en début de carrière.

## Ce que je recherche

- **Séniorité visée** : Senior ou Lead Flutter. Un poste « mid » un peu en dessous
  reste acceptable ; un poste junior ne l'est pas.
- **Rôle idéal** : Flutter en premier (ou mobile cross-platform), architecture mobile,
  travail sur SDK / plugins, CI/CD.
- **Régions** : Suisse (CDI ou freelance, les deux conviennent).
- **Langues** : français et anglais uniquement. Une offre exigeant l'allemand (ou une
  autre langue que je ne parle pas) n'est **pas** un bon fit.
- Télétravail ou présentiel : indifférent. Pas de plancher de salaire / TJM.

## Ne colle PAS à mon profil

- Postes purement backend, purement web, ou mobile non-Flutter (ex. natif iOS/Android
  seul, React Native seul) comme cœur du rôle.
- Postes junior / stage / alternance.
- Offres qui exigent une langue que je ne parle pas (allemand, mandarin, etc.).
